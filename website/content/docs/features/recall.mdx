Recall helps you pick up where you left off. Search past sessions across your coding agents, or ask a question about a project and follow the citations back to the original work.

![The Recall dashboard with Search and Ask tabs, project and agent filters, and project indexing controls](/screenshots/recall-overview.png)

## Search past work

Open **Recall** in the dashboard, pick a project, and use **Search**. Filter by agent to narrow the results. Use quotes for an exact phrase, such as `"render pipeline"`. Select a result to open its source. Keyword search works as soon as you have recorded sessions.

## Ask a question

Switch to **Ask**, choose a project, and ask in plain language. For example, “What did we decide about harness evaluations?” Recall shows what it searched and cites the sources behind its answer. Open a citation to inspect the original session or document.

Use **Ask history** to reopen a conversation and continue with follow-up questions. Its project and agent filters stay with the chat. Choose **New chat** to start with different filters. Conversations are saved on the machine running TokenTelemetry.

Ask uses the summarizer configured in Settings. Enable **AI summaries** there if Ask prompts you to set it up.

![Recall’s Ask tab showing the question, search and reading steps, and an answer with session citations](/screenshots/recall-ask.png)

## Set up semantic search

Semantic search finds results by meaning and includes indexed skills, plans, Markdown files, and images alongside sessions. Under **Recall → Embedding setup**, choose **Local (Ollama)** or **API**.

### Local with Ollama

Recall uses Google's **EmbeddingGemma 2 740M** (`embeddinggemma-2:740m`) by default. The model download is about 1.3 GB and supports text and image search. [Model details](https://ollama.com/library/embeddinggemma-2:740m)

| Where TokenTelemetry runs | How to start Ollama |
| --- | --- |
| macOS | Install and open the Ollama app. |
| Windows | Run the Ollama installer and open Ollama. It runs in the background. |
| Linux | Follow the Linux install guide. Start the Ollama service, or run `ollama serve` if you installed it manually. |
| Remote server or container | Run Ollama where the TokenTelemetry backend can reach it on loopback. If the backend runs in a container, its loopback is inside that container. Use the API option if Ollama runs at a separate network address. |

[Ollama downloads](https://ollama.com/download) · [Linux installation guide](https://docs.ollama.com/linux)

In **Embedding setup**, click **Download model** if prompted, then **Use local model**. Update Ollama if it reports that your version cannot load the model.

### Without Ollama

Choose **API** in **Embedding setup**. Select **OpenAI-compatible**, **Gemini**, or **Voyage**, then enter your provider's endpoint, embedding model, and API key when required. Match the dimensions to the provider's model and click **Save API settings**. Use HTTPS for a remote endpoint. HTTP is supported on loopback, for example when another local app serves an OpenAI-compatible embeddings API.

If you skip semantic setup, you can still search recorded sessions by keyword. Ask uses its own summarizer configured in Settings.

## Index project knowledge

Select a project and click **Index this project**. Follow the progress, then hover over a dot on the project knowledge map to identify its document. Click **Re-index** when new work appears to reuse existing embeddings. Changing the embedding model requires a full re-index.

## Where your data goes

Local Ollama keeps embedding requests on the machine running TokenTelemetry. If you choose a hosted embedding or summarizer provider, it receives the text needed for that operation after redaction. Hosted image embedding is off by default. Turning it on sends the original images to the provider.
