Recall helps you pick up where you left off. Search past sessions across your coding agents, or ask a question about a project and follow the citations back to the original work.

![The Recall page with Search and Ask tabs, project and agent filters, semantic search status and project indexing](/screenshots/recall-overview.png)

## Search past work

Open **Recall**, pick a project, and use **Search**. Click an agent badge to show only that agent. Use quotes for an exact phrase, such as `"render pipeline"`. Select a result to open its source. Keyword search works as soon as you have recorded sessions.

## Ask a question

Switch to **Ask**, choose a project, and ask in plain language, for example "What did we decide about harness evaluations?" Recall shows each search and reading step, then answers with citations you can open.

![An Ask answer with its search and reading steps and session citations, below the project knowledge map](/screenshots/recall-ask.png)

**Ask history** keeps your conversations on this machine. Reopen one to ask follow-up questions with the same project and agents. Ask uses the summarizer set in **Settings**; turn on **AI summaries** there if Ask asks you to.

## Set up semantic search

Semantic search is optional. It finds results by meaning and adds skills, plans, Markdown files and images to the results. Open **Recall → Embedding setup** and choose **Local (Ollama)** or **API**.

**Local with Ollama.** Recall uses EmbeddingGemma 2 740M (`embeddinggemma-2:740m`), a 1.3 GB download that handles text and images. Install and open [Ollama](https://ollama.com/download), then click **Download model** in Embedding setup. If TokenTelemetry runs on a server or in a container, Ollama must run on that same machine; otherwise use the API option. Update Ollama if it says your version can't load the model.

**API.** Choose **OpenAI-compatible**, **Gemini** or **Voyage**, enter the endpoint, model and API key, match the dimensions to the model, and save. Remote endpoints must use HTTPS.

## Index project knowledge

Select a project and click **Index this project**. The knowledge map fills in as documents are embedded; hover a dot to see which document it is. When new work appears, click **Re-index**: only new or changed content is embedded. Changing the embedding model requires a full re-index.

Only projects you index are embedded, and only sessions, images, skills, commands, agent definitions, plans, Markdown files and MCP config. Source code is never indexed.

## Where your data goes

With local Ollama, embedding stays on the machine running TokenTelemetry. A hosted embedding or summarizer provider receives the text it needs, after secrets are removed. Hosted image embedding is off by default; turning it on sends the original images to the provider.
