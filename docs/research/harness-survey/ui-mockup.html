Why the "not available" block matters

Silence reads as "we forgot". Naming the capability and the reason it isn't shown is the same contract _FEATURES_NOT_DETECTABLE already uses in main.py, and it distinguishes "this agent has no such feature" from "the feature exists but is unused here".

Handling rules baked into every panel
  • Credential values are never read — only that a file exists. Two traps: Cursor keeps live tokens in the same key-value table as ordinary UI state, and ~/.vibe/.env sits at the harness root, so a filename-based skip misses both.
  • No raw prompt or file content reaches the UI. Rewind points embed whole files, agentKv:blob:* is raw model I/O, and dictation history is voice. Counts, paths and timestamps only.
  • Panels build lazily on click, never during the 30-second session scan, and every SQLite handle opens read-only because five of these harnesses hold live WAL locks.
