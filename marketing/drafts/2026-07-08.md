### Variant B — "that dollar figure isn't your bill" (billing-mode demo)

A number I see people misread constantly: the cost figure on agent usage dashboards.

If you pay per token (API key), it approximates your bill. If you're on Claude Pro/Max or Copilot, it's an API-list-price *equivalent* — useful for comparing sessions, not an invoice. Your actual spend is much lower.

TokenTelemetry auto-detects which one you're on per agent (from each agent's own auth) and labels the number accordingly. You can override any agent under Settings → Billing & cost.

## Reddit — r/ChatGPTCoding value post

**Rotation:** ClaudeAI → **ChatGPTCoding** (this week) → LocalLLaMA → selfhosted. Monday's comments should have warmed the sub.

**Title:** What my coding agents actually cost me last month — and the three things I was getting wrong

**Body:**

I run Claude Code, Codex, and a couple of other agents daily, and until recently I couldn't have told you what any single task cost. Three things were tripping me up; sharing in case they're tripping you up too.

**1. The monthly bill tells you nothing about a task.** My June total was $[XX] API-equivalent across [X.XM] tokens — but the useful number was per-task: my biggest single refactor cost $[X.XX] and my median session was $[X.XX]. You can't plan around a monthly blob.

**2. Subagent spend is invisible by default.** When Claude Code spawns subagents (research, exploration), their tokens don't show in the parent session. One 50-minute session of mine used 294k tokens itself — its 8 subagents quietly used another 430k, about 1.5× the parent. If your tracking only sees parent sessions, you're missing most of the picture.

**3. If you're on a subscription, the dollar figure isn't your bill.** It's what the same usage would cost at API list rates. Useful for comparing sessions and agents, misleading if you read it as an invoice. (Bonus trap: Codex/Claude route programmatic use through separate credit pools than interactive use — worth knowing which pool a script is draining.)

I built an open-source dashboard, [TokenTelemetry](https://github.com/VasiHemanth/tokentelemetry), to see all this locally. It passively reads the log files your agents already write — no SDK, no cloud, no code changes, `npx tokentelemetry` and you're looking at your own numbers in about 30 seconds. Fixed a bug recently where newer Codex versions stopped updating their session index, so if you tried a tracker before and Codex sessions were missing, they show up now.

Happy to answer questions on how the cost math works — especially the subscription-equivalent framing, which is more subtle than I expected.

### 1. Three numbers people conflate
- Your bill (what you pay), API-equivalent (what the usage would cost at list rates), and marginal cost (what one more task costs you)

- Subagents burn tokens outside the parent session's numbers (real example: 294k parent, 430k across 8 subagents)
