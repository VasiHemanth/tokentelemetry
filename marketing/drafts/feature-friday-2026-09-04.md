## 3. LinkedIn Post

**Your AI coding agents are spending tokens you can't see. Here's the state of the tool that fixes that.**

TokenTelemetry is an open-source, 100% local observability dashboard for AI coding agents. No cloud account, no data leaving your machine, one install command.

This week was a quiet one — no new release — but here's the current state of the project:

**12 agents tracked in one dashboard:** Claude Code, OpenAI Codex, GitHub Copilot, Cursor, Grok Build, Google Antigravity, Cline, SmallCode, DeepSeek Harness, Meta Muse, and more. Each with full session traces, token breakdowns, and cost estimates.

**Local model users get real numbers:** energy consumption in watt-hours from your actual hardware, CO₂ estimates based on your grid's carbon intensity, and savings vs. cloud API pricing. Not vanity metrics — numbers derived from your chip's measured power draw.

**Subagent costs are no longer invisible:** when Claude Code spawns Explore or general-purpose agents, you see exactly what each one cost — priced by the model it actually ran.

256 commits, fully open source, zero config.

If you manage a team using AI coding tools and want visibility into what they actually cost — or if you're an individual developer who wants to understand your own usage — this is worth 30 seconds:

```
curl -fsSL https://raw.githubusercontent.com/VasiHemanth/tokentelemetry/main/install.sh | bash
```
