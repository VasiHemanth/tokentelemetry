**TokenTelemetry — Feature Friday update (2026-07-03)**

Quieter week — one feature shipped, plus docs cleanup:

**🧩 Cline + SmallCode now supported**
12 coding agents tracked now, up from 10.

- **Cline**: reads both the CLI's SQLite store (`~/.cline/data/db/sessions.db`) and the VS Code extension's `taskHistory.json`, de-duplicating sessions that appear in both. Subagent costs tracked separately from the parent, so delegation doesn't inflate totals.
- **SmallCode**: discovers `.smallcode/traces/` under your project directories automatically (or set `TT_SMALLCODE_ROOTS` for non-standard locations). Captures prompt/completion tokens, model, and tool-call timing.
