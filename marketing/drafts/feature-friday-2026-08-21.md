## LinkedIn post

**Your AI coding agents just got more observable.**

This week in TokenTelemetry (open-source, 100% local, zero-config observability for AI coding agents):

We shipped DeepSeek Harness support — the newest entrant in the AI coding agent space. What makes this interesting from an observability standpoint: DSH sessions can mix local models (Ollama) with cloud API calls in a single session. TokenTelemetry prices each segment correctly — local by your electricity rate, cloud by the provider's API rate — so engineering managers see real cost, not a blended average.

Each session trace now shows a latency breakdown (time to first token, throughput, LLM time vs tool time), and subagent sessions link back to the parent run. If you're evaluating DSH alongside Claude Code, Codex, Copilot, or Cline, you can now compare them apples-to-apples in one dashboard.

Community highlights: @hwantage contributed a step index filter for navigating long traces (thousands of steps become manageable) and auto-scrolling during replay. Three PRs merged this week from contributors — the kind of momentum that makes open-source work.

We also fixed a Debian/Ubuntu install blocker and added automatic `uv` detection for ~7x faster setup when it's available.

TokenTelemetry tracks 9 agents, runs entirely on your machine, and takes one command to install:

```
curl -fsSL https://raw.githubusercontent.com/VasiHemanth/tokentelemetry/main/install.sh | bash
```
