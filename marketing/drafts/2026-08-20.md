### Variant A (community contributor spotlight)

Open-source is better when people show up and fix things.

Last month @KyleHutchinson (mariadb-KyleHutchinson on GitHub) noticed that TokenTelemetry stopped tracking Claude Code sessions accurately once you passed 100 — older sessions sat frozen as blank rows with zero tokens. He didn't just report it; he dug in and fixed it (PR #131).

The result: every session is now fully scanned regardless of history size, with a local cache that keeps repeat scans fast. If you've been using Claude Code for months, your dashboard now shows your real totals for the first time.

That's the kind of contribution that makes maintaining an open-source project worth it. Thank you, Kyle.

TokenTelemetry is a free, local observability dashboard for AI coding agents — Claude Code, Codex, Gemini CLI, Cursor, Copilot, and 6 more. No signup, no cloud, 30-second install.
