## X / Twitter — tip: a feature most people miss

### Variant A — the "Delegated work" card (subagent spend)

A TokenTelemetry feature I rarely see mentioned: subagent costs.

When Claude Code spawns subagents (Explore, general-purpose, custom), their tokens don't show up in the main conversation — on my machine that was millions of invisible tokens. Open any session and the "Delegated work" card lists each subagent's task, model, tokens, and cost — priced by the model it actually ran, so a Haiku Explore isn't billed as Opus.

Analytics also ranks subagent types by cost. If general-purpose runs cost you 5× what Explore does for similar work, that's a delegation habit worth changing.

### Variant B — "no recorded use" on the Config page

Easy cleanup most people miss: TokenTelemetry records which skills you actually invoke and how often each MCP server gets called, then overlays that on your project's Config page — every installed skill, command, subagent, and MCP server.

Anything marked "no recorded use" is a candidate to remove. Unused MCP servers aren't free: their tool definitions ride along in every request's context. I found [N] servers I hadn't called once. (Fill [N] from your Config page before posting.)
