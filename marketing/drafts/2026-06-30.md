### Variant B — Attribution cost tree

TIL: when a Claude Code session spawns subagents, the parent session's cost card used to show ~$0.02. The subagents doing most of the work were invisible.

TokenTelemetry's attribution cost tree rolls the full delegation chain into the parent — so you see what a task *actually* cost, not just the orchestrator's slice.

Open any session with children → Delegated work card → full breakdown by subagent type and model.
