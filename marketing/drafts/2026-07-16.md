### Variant B — visibility milestone (use if you'd rather not name contributors publicly)

You can now see the token cost of every single step in an AI agent session — not just the session total.

Open a trace and each step carries a chip with the tokens that API call used. It sounds small, but it changes how you debug cost: instead of "this session was expensive," you can point at the one step — a giant file read, a runaway subagent — that actually did it. Same idea as a flame graph, but for tokens.

This works across every agent TokenTelemetry tracks, and it reads the logs those agents already write to disk — no SDK, no cloud, no code changes.

Open source, 100% local: github.com/VasiHemanth/tokentelemetry
