### Intro (100w)
The problem: you run Claude Code, the session ends, the cost summary looks reasonable — but where did those tokens go? Claude Code spawns Explore, general-purpose, and custom subagents for you without asking. Before this week, their usage was invisible in the parent session.

### Section 1: How Claude Code delegation works (150w)
- Brief: when you trigger a task, Claude Code decides whether to handle it inline or delegate to a subagent
- Subagents can run on *different models* (e.g., Explore on Haiku, general-purpose on Sonnet) — so the parent session's model label is misleading for cost
- This is documented but easy to miss; most users don't realize Haiku vs Opus has a 20x cost difference per token

### Section 2: What TokenTelemetry now shows (200w)
- "Delegated work" card on each session page: lists each spawned task with its model, token count, and cost
- Drill-in: click any row → slide-over with the full child trace (tool calls, turns, output)
- Analytics → Delegation & ecosystem: per-agent-type ranking — if general-purpose agents cost you 5× Explore agents for similar work, you'll see it
- Cross-agent: Grok Build, Codex, and Antigravity CLI also link parent↔child sessions now

### Section 3: The two things that actually surprised me (200w)
1. Explore agents on Haiku are genuinely cheap — but general-purpose agents default to a heavier model. Once visible, you can choose to delegate differently.
2. The credit pool split: Claude's interactive and programmatic (SDK/CI) pools don't share budget. The programmatic pool stops at $0 silently. Visible now in Settings per agent.

### Section 4: How to try it (100w)
```
npx tokentelemetry
```
Reads logs Claude Code already writes. No config, no sign-up, no data leaves your machine. If you've used Claude Code today, your sessions are already there.

If you're optimizing for cost, knowing which model handled which work matters — but the session summary only shows the parent model.

>
> This surprised me more than the model split. Claude has two credit pools: interactive (you typing in Claude.app or Claude Code terminal) and programmatic (claude -p, the Agent SDK, CI). > You can now see which pool each agent drains, pool sizes by plan tier, and a stops-at-$0 warning. Settings → expand any agent.
