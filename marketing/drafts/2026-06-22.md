## LinkedIn — Cost-visibility post (longer version of X insight)

> **If a coding agent spawns a subagent, do you know what model it ran on — or what it cost?**
>
> Most teams don't. When Claude Code (or similar agents) delegate work to subagents — a research pass, a "general-purpose" task, a custom agent — those tokens have historically been invisible, folded into the parent session's total with no breakdown.
>
> That matters for two reasons: subagent calls can run on a different model than the parent session, and the cost difference between agent types for similar work can be large — if a general-purpose agent is costing you 5× what an Explore agent does for the same kind of task, you'd never know without per-subagent visibility.
>
> TokenTelemetry now shows this directly: every session page has a "Delegated work" card (task, model, tokens, cost per subagent), and Analytics has a Delegation & ecosystem section ranking subagent types by cost. It also tracks which skills and MCP servers actually got used per session — useful for cleaning up tooling nobody's touching.
>
> All read locally from logs already on disk. No SDK, no cloud account, no code changes.
>
> → github.com/VasiHemanth/tokentelemetry
