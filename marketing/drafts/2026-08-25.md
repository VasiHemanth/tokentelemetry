### Variant B (worktree rollup — multi-agent angle)

Feature most people miss in TokenTelemetry: git worktree rollup.

If you run different agents in different worktrees of the same repo (Claude Code in one, Codex in another), they used to show as separate projects with split totals.

Now they roll up under one project with a per-worktree breakdown — including deleted worktrees. So you see the real total cost of that repo, not fragments.
