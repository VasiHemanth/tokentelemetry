## LinkedIn — cost-visibility post (longer version of the X insight)

**A cost dashboard showing $0.00 is not good news. It's usually a bug.**

I build TokenTelemetry, a local dashboard that shows what AI coding agents actually cost. Last week a user reported sessions that displayed a cost of exactly $0.00 — and they weren't free runs. They were routed through a proxy endpoint the tool couldn't map back to a real model, so it defaulted the price to zero.

That's the dangerous kind of wrong. A crash you notice. A confidently-wrong number you act on. Zero looks like a win, so nobody questions it — right up until the real bill shows up.

Two things went out to fix the category, not just the case:

First, proxy and custom-endpoint sessions now get re-priced against real model rates instead of silently falling to zero. Thanks to the user who reported it — this is the second month running where a "that number looks off" report turned straight into a merged fix.

Second, the pricing data itself now refreshes weekly from an open source (models.dev) and ships with each update. Model prices move; a dashboard that hard-codes them drifts wrong without ever erroring. Pulling fresh rates keeps the math honest — and it's still read entirely on your machine, no new outbound calls.

The throughline for Money week: cost tools fail quietly. If you track agent spend with anything, spot-check one "$0.00" or suspiciously-round session against its raw log this week. Ten minutes, occasionally very informative.
