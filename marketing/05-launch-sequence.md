# 14-Day Launch Sequence

Objective: go from 103 stars / no community → live Discord, posting rhythm on all channels, and a Show HN that lands on a warm audience. Sequencing matters: **community infrastructure first, broadcast second** — traffic with nowhere to land is wasted.

## Week 1 — Foundation + soft launch

**Day 1 (setup day)**
- Build Discord per `03-discord-structure.md`; invite link into README, site, X bio
- Verify README hero GIF/screenshot is current (it's your landing page for everything below)
- Cowork scheduled tasks live (done if you approved them this session)

**Day 2**
- X: soft announcement — "TokenTelemetry now has a Discord" + dashboard screenshot + what the project is, for new followers
- Post your own dashboard in #show-your-dashboard to seed it

**Day 3**
- Dev.to article #1 (the SEO anchor): "How to see exactly what Claude Code costs you — free, local, 2 minutes." Cross-post link to X.
- LinkedIn: first post — the founder story angle ("AI agents burn tokens invisibly; I built the dashboard I needed")

**Day 4**
- Reddit value post #1 in r/ClaudeAI: data-first ("I analyzed my month of Claude Code usage — here's what surprised me"), tool mentioned once, Discord not linked (let people ask)
- Stay in the thread all day answering comments — this is the day's main work

**Day 5 (Feature Friday #1)**
- X thread: what shipped this week (from UPDATE.json roundup draft)
- Discord #announcements changelog
- Personally DM/invite 5–10 people who've engaged with the repo (issue filers, PR authors) to Discord

**Day 6–7**
- Light: X build-in-public post Saturday; rest Sunday
- Review metrics digest Sunday evening; note what resonated

## Week 2 — Broadcast

**Day 8**
- Reddit value post #2, r/LocalLLaMA or r/selfhosted angle ("100% local observability for AI agents — no cloud, reads logs you already have")
- LinkedIn: milestone post (stars + Discord members + "week 1 of building in public")

**Day 9**
- Dev.to article #2: "Langfuse vs LangSmith vs TokenTelemetry — when you need each" (fair, factual; this ranks forever)
- X: thread version of the comparison

**Day 10 (Show HN day — Tue/Wed, 8–10 AM ET)**
- Title: `Show HN: TokenTelemetry – Local, zero-config cost dashboard for Claude Code and 35+ agents`
- First comment: your story, architecture notes, honest limitations, what feedback you want (full playbook: `reference/go-to-market-growth-strategy.md` §2)
- Clear your calendar: answer every comment for 6+ hours. Don't ask anyone to upvote (HN detects voting rings).
- Pin Discord message so new arrivals get greeted

**Day 11**
- HN follow-through: file issues from feedback publicly, thank contributors
- X: "What I learned from Show HN" recap (performs well regardless of how HN went)

**Day 12 (Feature Friday #2)**
- Ship something visible from week-1/HN feedback if possible — "you asked, it's live" is the strongest possible community signal
- Standard Friday thread + changelog

**Day 13–14**
- LinkedIn + X: 2-week recap with numbers (stars, Discord members, best post)
- Sunday: review digest, set week-3 angle, fall into the standing weekly calendar (`02-weekly-content-calendar.md`)

## Success markers (day 14)

- Discord: 30–50 members, #show-your-dashboard has non-you posts
- X: posting streak intact, follower growth trending up
- GitHub: 150–250 stars (HN swing is wide — front page can mean +500)
- SEO: 2 Dev.to articles indexed
- Rhythm: Cowork drafts flowing daily, your time ≤1 hr/day

## If HN flops

Front page is a lottery. The sequence still works — Reddit + SEO + Feature Friday compound regardless. Re-submit HN in 4–6 weeks with a new angle (a major feature, the Hermes integration story). Many projects hit front page on attempt 2–3.
